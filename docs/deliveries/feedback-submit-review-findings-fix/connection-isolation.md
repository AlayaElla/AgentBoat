已修复 [审查第 2 项](../feedback-submit-ponytail-review/review.md)。在 `0cb926f` 上分别给 `workspace.links` 和 `workspace.connections` 注入 `version: 2`，两例均在启动阶段抛错。独立的概览读失败和项目列表可读已由原审查复现。

启动分别记录两个连接区的故障，继续恢复主绑定、在途通知和 CLI。概览返回可用项目、待验收项和健康连接，在故障连接区提示保留原数据、核对插件版本，恢复后重试。目录操作继续经过原校验。恢复兼容目录后，刷新概览即可重新启动工作间连接，外部 A2A 复用现有的按连接启动流程。
