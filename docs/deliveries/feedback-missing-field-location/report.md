# 反馈底栏缺项定位

待提交的反馈缺少必填内容时，底栏显示具体事项和字段，例如「成果 a2 · 缺修改意见」。「去填写」打开对应的待处理详情并聚焦输入框。同一任务的多条验收按各自的草稿键定位。点击「已选」可以展开查看每条缺项。

提示和提交共用已有的有效选择集与必填校验。空白字符视为空，验收通过留言和预设决定的补充说明仍可留空。修改意见、「其他」答案和受阻备注缺失时，补齐后即可提交。
